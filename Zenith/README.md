# Zenith Client (Fabric, Minecraft 1.21.4)

Client-side PVP HUD mod. Needs Fabric Loader + Fabric API.

Controls: Right Shift = menu, hold C = zoom (rebind in Controls).

Build without installing anything: push this folder to GitHub, open Actions, download the jar from the finished run.
Build on PC: install JDK 21 + Gradle 8.12, run `gradle build`, jar is in build/libs/.

Edit modules in src/main/java/net/zenith/Modules.java. Fog settings: FogModule.java.
